# Glossary

| Term | Definition |
|---|---|
| Aggregate | A consistency boundary — a cluster of entities and value objects that change together under one invariant set |
| Bounded context | A region of the domain with its own ubiquitous language |
| Command | A request to change state. Validated against invariants; refused or accepted |
| Tenant | The isolation key. Every stored row and every command carries the tenant |
